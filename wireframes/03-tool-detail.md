## Key Components

### Image Gallery
- **Main Image**: Centered, responsive size
- **Thumbnails**: 3-5 small images below (clickable to swap)
- **Zoom**: Click to expand (lightbox modal)
- **Placeholder**: Gray background if no image

### Quick Specs Card
- **Purpose**: At-a-glance key information
- **Fields**: Power, Weight, Speed, Torque, Dimensions
- **Design**: Card/panel with light background

### Add to Collection Panel
- **Quantity Selector**: Dropdown or + /- buttons
- **Collection Checkboxes**: Multi-select existing collections
- **New Collection**: Option to create new collection inline
- **Submit Button**: "Add to Collection" (primary color)

### Full Specifications Tabs
- **Tab 1**: Technical Specs (power, speed, torque, etc.)
- **Tab 2**: Features (ergonomic, LED, etc.)
- **Tab 3**: Included Accessories (batteries, charger, case, etc.)
- **Tab Design**: Underline indicator on active tab

### L-Boxx Compatibility Section
- **Compatible Boxes**: Chips/badges showing L-Boxx models
- **Best Match Highlighted**: Border or background highlight
- **Inlay Recommendation**: Card with image, name, price
- **CTA**: "Learn More" (link), "Add with L-Boxx" (button)

---

## Accessibility Notes

- ✅ **Image Gallery**: ARIA labels for each thumbnail
- ✅ **Tabs**: `role="tablist"`, `aria-selected` on active tab
- ✅ **Quantity Selector**: Proper input with label
- ✅ **Checkboxes**: `<label>` associated with each checkbox
- ✅ **Contrast**: All text meets 4.5:1 ratio minimum
- ✅ **Keyboard Nav**: All interactive elements focusable

---

## Interaction Notes

1. **Image Swap**: Click thumbnail → main image updates instantly
2. **Zoom**: Click main image → full-screen lightbox modal
3. **Tab Switching**: Click tab → content swaps (smooth transition)
4. **Add to Collection**: 
   - Single click if one collection exists
   - Modal if multiple or new collection needed
5. **Quantity Change**: Real-time validation (1-100 allowed)
6. **Mobile Tabs**: Swipe left/right to switch tabs
