# L-BOXX Tool Finder

Private web app for managing your own tool collection and mapping tools to matching L-BOXX and inlay options.

## Live URL

https://macalexister.github.io/Lboxx/

## Scope

- Search tool models quickly
- Track what you already own
- Show matching L-BOXX sizes and inlays
- Run fully in the browser (static GitHub Pages app)

## Project Positioning

This is a private, independent project.  
No affiliation, endorsement, or sponsorship by any manufacturer.

## Local Start

```bash
cd bosch-pro-tool
python3 -m http.server 8000
```

Open `http://localhost:8000`.
